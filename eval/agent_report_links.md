## Найдено и починено в ходе проверки
1. **hh.py: токен терялся** во внутренней ветке клиента (`headers=_HEADERS` без
   Authorization) → 403 «найм не проверен» даже с настроенным HH_APP_TOKEN. Исправлено:
   передаётся `headers` с токеном. Тест `test_hh_sends_token_in_fallback_client`.
2. **hh.py: запрос полным юр. именем давал found=0** («ООО "БПМСОФТ"» — hh ищет
   подстроку, работодатели записаны как «БПМСОФТ»). Исправлено: `_search_query()`
   вытаскивает имя из кавычек / срезает правовую форму. Тесты
   `test_hh_search_query_strips_legal_form`, `test_hh_full_name_finds_vacancies`.
3. Сайт cardsmile.ru реально недоступен (ConnectError) — «сайт не открыт» честно
   попадает в что_не_собралось; это свойство компании, не баг.
4. **rmsp-ссылка была 404**: правильный роут `search.html?query=`, а не `/search`.
   Исправлено в context_builder.
5. **Карточка checko.ru/company/{ИНН} отдаёт 404** (голый ИНН не работает вовсе,
   сайт отвечает только слагами вида `bpmsoft-{ОГРН}`). Карточные ссылки переведены
   на Контур.Фокус по ОГРН (`focus.kontur.ru/entity?query={ОГРН}` — проверено:
   200 + название компании в заголовке; по ИНН даёт промежуточную страницу, поэтому
   именно ОГРН). Места: source_links контекста, Fact.source_url в checko.py,
   source_urls в scoring/engine.py. `checko.ru/person/{ИНН}` валиден — оставлен.

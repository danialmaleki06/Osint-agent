## Исправления

- Убран предел в два домена: опрашиваются все домены источника.
- Сохраняется тематический шаблон запроса при ограничении на домен.
- Каталог общей аналитики использует реальные ID счётчиков вместо поиска общих слов.
- Пакетные проверки активов получают названия и сайты, как одиночные проверки.
- Сетевой отказ не превращается в «ВЭД нет», «связей нет» или успешный нулевой ответ.
- Включена проверка TLS при загрузке сайта; временные сетевые ошибки и 5xx повторяются ограниченно.
- Проверка SSL использует настроенный интерфейс и публичный DNS с сохранением SNI.
- ЕРКНМ использует настроенный прямой маршрут; прерванный ZIP при повторе загружается заново.
- Checko и веб-поиск объединяют одинаковые параллельные обращения и кешируют только успешные ответы.

# Защищённый минимум поиска и проверка СМИ, 19 ноября 2026

## Что исправлено

Поиск официального сайта выполняется раньше репутационных проверок.
Раньше его платные повторы могли занять бюджет этих проверок.
Теперь до сборки контекста защищаются первые попытки репутационных
направлений: 2 для brief, 4 для standard, 6 для full.

При бюджете 4 рубля остальные задачи до репутации могут использовать
не более двух платных попыток в режиме full. Каждое из шести направлений
получает первую попытку до повторов других направлений. Неиспользованный
резерв освобождается. Полезные результаты сохраняются. Сбой поиска теперь
виден в поле `проверка_репутации`, отдельно от отсутствия находок.

Это защита распределения бюджета, а не гарантия ответа внешнего сервиса.
При установленном пользователем бюджете ниже 2,928 рубля шесть платных
попыток не помещаются. Глубина поиска, набор направлений и потолок 4 рубля
не изменены. Доступ к Checko и другим прямым API не зависит от этого резерва.

## Проверка отказов

Интеграционные тесты используют реальный код досье, бюджета, цепочки
поисковиков и репутационного сборщика с HTTP-ответами, заданными через respx.
DuckDuckGo отвечает 202, Yahoo — 500, работает только Яндекс.
Поиск сайта пытается израсходовать свободные слоты первым.

- При успешном Яндексе все шесть репутационных направлений получают ответ.
- При 503 одного направления остальные пять всё равно получают ответ;
  недоступное направление отмечается как partial, без ложного чистого результата.
- В обоих сценариях максимум восемь платных HTTP-попыток, резерв 3,904 рубля.
- Проверяется освобождение неиспользованного резерва и статус unavailable
  при отказе всех репутационных направлений.

Это моделирование отказов, не живые платные обращения к Яндексу.
